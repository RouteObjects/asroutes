# Security Policy

## Supported versions

Security fixes are provided for the latest released version of `asroutes`.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1   | No        |

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue or
discussion. Use GitHub's private vulnerability reporting form:

https://github.com/RouteObjects/asroutes/security/advisories/new

Include the affected version, operating system, reproduction steps, expected
behavior, observed behavior, and any potential impact. Reports will be
acknowledged and assessed on a best-effort basis. A coordinated disclosure
date will be agreed on when a fix is required.
