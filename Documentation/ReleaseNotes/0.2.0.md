# asroutes 0.2.0

This release updates the dependencies used by the SwiftNIO IRRd
client and CLI. The command-line flags, raw/grouped/JSON output formats,
direct-ASN lookup APIs, and macOS 15/iOS 18 deployment minimums are unchanged.

## Compatibility and migration

Source builds and SwiftPM library consumers now require Swift 6.2 or newer,
up from Swift 6.1 in 0.1.0. Prebuilt command-line executables do not require a
Swift toolchain.

The `swift-cidr` requirement changes from `0.4.x` to `0.8.x`, with 0.8.1 as
the minimum. Applications importing `CIDR` directly should update their own
package requirement to `.upToNextMinor(from: "0.8.1")` alongside
`.upToNextMinor(from: "0.2.0")` for asroutes. Applications retaining Swift 6.1
or `swift-cidr` 0.4.x can continue using asroutes 0.1.0.

`swift-cidr` 0.8 includes contextual address equality and hashing, preserves
prefix context in network endpoints and iteration, and provides explicit
labeled containment operations. Review its
[migration notes](https://github.com/RouteObjects/swift-cidr/blob/0.8.1/Documentation/ReleaseNotes/0.8.0.md)
when using the returned network values. Version 0.8.1 makes its existing
containment implementation available for cross-module specialization.

IRRd responses with malformed prefix lengths such as `/024`, `/+24`, or
`/-0` are now rejected. Valid prefixes remain canonical, numerically sorted,
and exact-deduplicated; covered more-specifics remain present without
aggregation. New regression tests cover malformed prefix lengths in both
address families.

## Dependencies and release tooling

- `swift-cidr` 0.8.1, updated from 0.4.0 in the published 0.1.0 binaries.
- SwiftNIO 2.104.0, updated from 2.100.0.
- Swift Argument Parser remains at 1.7.0.
- Linux builds use the pinned Swift 6.2.4 Ubuntu 22.04 toolchain.
- Dependency notices match the resolved package versions and revisions.
- Artifact upload/download actions include their patch-level retry fixes.

The release workflow builds macOS and Linux executables for ARM64 and
x86-64, packages the license and consolidated notices, and generates
`SHA256SUMS`. Linux archives are checked for Swift runtime dependencies and
executed in clean Ubuntu 22.04 containers without Swift installed.
